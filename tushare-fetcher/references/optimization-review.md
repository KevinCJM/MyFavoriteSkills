# 后续强化建议（2026-09-14）

对比来源：

- [官方 tushare-data 技能](https://github.com/waditu-tushare/skills/blob/5e12b31d09123e262c5fb38564e80c26d05cb830/tushare-data/SKILL.md)，版本 1.1.16。
- [官方接口目录](https://github.com/waditu-tushare/skills/blob/5e12b31d09123e262c5fb38564e80c26d05cb830/tushare-data/references/数据接口.md)。
- 本技能本次修复后的生成、运行、冒烟与固化代码。

定位建议：保留下载工程工具的边界，吸收官方对中文任务、标的、时间和输出口径的理解。把用户需求整理成明确取数计划，再交给唯一下载实现。

## 已落实的修复

单次请求计数、永久错误停止、带抖动的有界重试、共享限流、连接/读取/空闲/总时限、显式分页、触顶失败、断点与分片哈希、空结果复核、冒烟证据校验及固化预检已经实现。详见 [运行契约](runtime-contract.md)。测试使用假 HTTP 与临时目录，未据此声称真实账户接口已验证。

## 建议优先级

| 优先级 | 强化方向 | 可交付的具体结果 | 验收重点 |
| --- | --- | --- | --- |
| P1 | 接口目录更新与结构化约束 | 按官方 API/doc_id 对齐；记录来源、核对时间、积分、独立权限、频率、行数上限、分页与更新时间。缺失事实显式标为未知。 | 目录差异可审阅；项目目录优先；过期信息不会自动启用执行；权限与积分分开。 |
| P1 | 中文需求转取数计划 | 从“近两年基金净值”“最近八季度财报”等表述生成标的、时间、字段、接口组合、分片列表和请求预算；先显示必要范围。 | 基金/ETF/股票/指数和重名标的正确区分；只有影响结果的歧义才澄清；计划交给现有生成器。 |
| P1 | 时点、字段与业务键契约 | 为高频接口登记交易日、公告日、报告期、复权、单位、唯一键和字段 dtype；明确缺失/修订/源冲突处理。 | 公告日不被报告期替代；财务累计值不当单季值；冲突不静默覆盖；下载成功与 PIT 合格分开。 |
| P2 | 可验证的全历史规划 | 根据交易日历与标的有效区间生成完整分片；支持少数明确契约接口的自适应日期拆分。 | 无漏段/重复；上市前空数据有依据；触顶能拆小或失败；不声称当前 strategy 标签已实现这些能力。 |
| P2 | 增量与大数据输出 | 按接口定义增量水位和回补窗口；以分片清单和 Arrow/Parquet 流式写入降低最终拼接内存。 | 重复运行幂等；供应商修订可追溯；实测峰值内存与恢复耗时；不直接把最新下载时间当业务水位。 |
| P2 | 交付更易读 | 取数后先返回范围、行数、缺失/失败分片、文件路径；研究任务的分析说明由上层按需调用。 | 读者能快速判断“下载了什么、还缺什么、能否复用”，无需阅读长日志。 |
| 按需 | 跨机器配额 | 多主机真实并行时接入统一配额服务。 | 全部客户端纳入同一账户配额；当前本机 SQLite 不能被宣称为跨机器限流。 |

当前官方目录有 240 条记录、239 个不同接口名；本地内置 JSON 有 229 条记录、228 个不同接口名，生成时间为 2026-06-01。官方多出的 11 个名称为 `etf_sh_cons`、`etf_sz_cons`、`p_delete`、`p_get`、`p_list`、`p_save`、`pro_bar`、`rt_etf_min`、`rt_etf_min_daily`、`stk_factor`、`sw_mins`。这是目录对比，不是 11 个均可通过通用查询下载的结论：`pro_bar` 有 SDK 组合语义，自定义组合中的保存/删除是写操作，必须另行区分授权和执行路径。

也应清理目录中预设 10000 积分的派生可用性描述，改为中性的接口事实。当前生成器实际读取调用参数/用户本地积分配置，不能使用这些历史假设替代当前账户事实。

## 借鉴时的取舍

官方的任务分类、标的解析、默认时间窗口、财务口径和人类友好输出值得吸收。保持主 SKILL 简洁，详细规则按需放入引用文档；不必复制其整篇长入口或另建一套下载器。

官方示例也需要校验。例如 [基金示例](https://github.com/waditu-tushare/skills/blob/5e12b31d09123e262c5fb38564e80c26d05cb830/tushare-data/scripts/fund_data_demo.py) 使用 `fund_name`，而 [fund_basic 在线字段](https://tushare.pro/wctapi/documents/19.md) 定义的是 `name`。示例来源不能替代接口契约和验证证据。
